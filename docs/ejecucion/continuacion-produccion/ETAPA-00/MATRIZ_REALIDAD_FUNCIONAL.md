### Leyenda de Estados:
- **IMPLEMENTADA Y CONECTADA**: Existe en backend relacional (`/api/v1`) y el frontend React la consume activamente mediante peticiones HTTP.
- **IMPLEMENTADA SOLO EN BACKEND**: Existe en servidor Express y SQLite, tiene pruebas unitarias/integración, pero la interfaz cliente (UI) no la invoca o usa almacenamiento local (`localStorage` / mocks).
- **SIMULADA/DEMO**: Funciona en frontend basada en datos en memoria, `localStorage` o lógica estática sin persistencia en base de datos.
- **INCOMPLETA**: La funcionalidad existe parcialmente pero carece de cobertura integral (ej. faltan semanas lectivas, recursos reales o integración cruzada).
- **SIN CONFIGURACIÓN EXTERNA**: Implementada pero bloqueada o degradada por ausencia de claves de API externas, credenciales de producción o variables de entorno del proveedor.
- **NO IMPLEMENTADA**: No existe en frontend ni en backend.
