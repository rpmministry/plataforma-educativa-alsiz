## 4. Normas de Operación
1. **Aislamiento**: Ningún cambio se introduce directamente en `main`. Se trabaja en rama local por etapa.
2. **Sin operaciones destructivas no autorizadas**: Prohibido push, rebase destructivo, borrado de archivos o descartes sin autorización explícita.
3. **Seguridad**: Prohibido exponer claves, tokens, secretos o datos personales en el código o la documentación.
4. **Validación real**: Las pruebas deben ejecutarse en el entorno y registrar su código de salida real (`02_PRUEBAS.md`).
5. **Cierre formal**: Ninguna etapa se da por cerrada sin su informe completo (`06_CIERRE.md`) y estado calificado.
