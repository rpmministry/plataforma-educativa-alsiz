# Índice General de Matrices Temáticas de Profesores IA
## Plataforma Educativa ALSIZ para Ekballo Church

Este directorio contiene las **Matrices Temáticas Pedagógicas Versionadas (v1.0.0)** para cada una de las 20 materias activas de **Gael (4.º EGB Elemental)** y **Avril (8.º EGB Superior)**.

Cada matriz temática estandariza los 12 ejes pedagógicos requeridos:
1. Competencias y destrezas clave oficiales (MINEDUC, CSTA, MCER, Ekballo).
2. Secuencia didáctica anual en 3 unidades trimestrales.
3. Prerrequisitos cognitivos y conceptuales.
4. Vocabulario técnico graduado (enfoque bilingüe).
5. Errores conceptuales frecuentes y andamiaje socrático.
6. Explicaciones graduadas (Concreto, Pictórico/Visual, Abstracto/Formal).
7. Actividades socráticas interactivas.
8. Respuestas de referencia y criterios de aceptación.
9. Rúbricas analíticas formativas (Escala 0.00 a 10.00 con umbral 7.00/10.00).
10. Fuentes válidas del Centro de Conocimiento con etiquetas de citación formal (`[DOC#C1]`).
11. Límites de seguridad y protocolos de derivación (LOPDP y protección infantil).
